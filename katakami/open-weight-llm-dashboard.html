今回の更新

Artificial Analysis の現行指標は Intelligence Index v4.3です。旧版の v4.1.1 と v4.3 は評価セットが異なり、数値を直接比較できません。この版では旧スコアを混在させず、AAの「Current」表示で確認できる各総パラメータ帯の上位チェックポイントを中心に再構成しました。同一チェックポイントに複数の reasoning effort がある場合は、原則として最も高い現行スコアだけを残しています。これは全369件の履歴データベースではなく、2026年9月18日時点の現行候補を見比べるダッシュボードです。

横軸と形

横軸の既定値は √(総パラメータ×活性パラメータ) です。これは保存容量に効く総パラメータと、1トークンあたりの計算量に効く活性パラメータの対数中点です。実機価格は総パラメータ、生成速度は活性パラメータの影響を強く受けるため、軸切替で両方を確認してください。丸はDense、ひし形はMoEです。

指標・データの読み方と注意点（必読）

収録の方針

このダッシュボードは Artificial Analysis が現行指標でスコアを公開しているオープンウェイトモデルを、原則すべて写したものです（49系列・279件）。API専用モデルは参照点として別枠に、パラメタが公開されていてもAAに指標がないモデルは軸下の帯に置いています。「主要ファミリーだけ」という当初の方針から変えたのは、小型帯が空っぽだと「小さくても賢い」という図の主題そのものが成立しないためです。現在、実効サイズ4B以下でスコアがあるモデルは35件あります。

横軸の定義

MoEモデルのサイズは √(総パラメタ × 活性パラメタ)（幾何平均）を既定値としています。これは「記憶容量に効く総パラメタ」と「1トークンあたりの計算量に効く活性パラメタ」の対数中点にあたり、片方だけを見ると疎なMoE（例: 活性3BのQwen3.5 35B A3B）と密モデルが不当に並んでしまう問題を緩和します。密モデルでは総＝活性なので値は総パラメタと一致します。より厳密に比較したい場合は横軸を「総パラメタ」「活性パラメタ」に切り替えて両端を確認してください（幾何平均はこの2つの中間に必ず入ります）。

Intelligence Index のバージョン問題（最重要）

Artificial Analysis の Intelligence Index は v1 → v2（2025-02）→ v3（2025-09）→ v4.0（2026-01）→ v4.1（2026-06）→ v4.1.1（2026-08） と繰り返し改訂されており、バージョン間でスコアは比較できません。飽和したベンチを外し難しいエージェント系ベンチを入れるたびに全体が圧縮されるため、同じモデルの数値が大きく動きます（例: Kimi K2 Thinking は公開時 v3 で 67、現行 v4.1.1 では 33。DeepSeek V3.2 は v3 で 66 → 現行 32）。

本ダッシュボードは すべての点を現行 v4.1.1 に統一しています。AA が旧モデルを現行指標で再採点した値を使っているため軸として整合しますが、その代償として2つの注意があります。

  • 2023〜2024年のモデルは 1〜9 に強く圧縮され、当時の相対的な優秀さ（Mixtral が GPT-3.5 級だった等）は表現されません。低い側の点の差は過小評価して読むべきです。
  • 古い・非推奨モデルの多くは AA が「推定値（independent evaluation forthcoming）」と注記した値で、実測の再走ではありません。Llama 3.1 405B、DeepSeek LLM 67B、Mixtral 系、Grok 系、MiniMax M1、Tiny Aya などが該当します。表とツールチップで確認できるものには「AA推定」バッジを付けています。
  • 改訂の影響が一目で分かる実例：MiniCPM5-1B は公開時（v4.0、2026-05）に 17.9 と発表されましたが、現行 v4.1.1 では 12 です。MiniCPM-V 4.6 1.3B も 13 → 4。Qwen3.5 の小型4種は公開時記事で 9B=32 / 4B=27 / 2B=16 / 0.8B=9 と発表されましたが、現行では 22 / 20 / 7 / 5 です。モデルは1文字も変わっていません。v4.1がエージェント系ベンチの比重を34%へ引き上げた結果、小型モデルほど大きく下方に圧縮されました。AAの公開時記事の数値と本ダッシュボードの数値が食い違うのは、これが理由です。

ページ表記が旧版のままのモデル

次のモデルのAAページは、指数のバージョン表記が v4.1.1 ではなく v4.1 または v4.0 のまま描画されます：Llama 2 Chat 13B、DeepSeek R1 Distill Llama 8B、DeepSeek-V2.5 (Dec '24)、Granite 4.0 H 350M、Phi-4 Multimodal、Olmo 3 7B Think、Molmo2-8B、Ring-1T、Ling-flash-2.0、Ring-flash-2.0、Ling-mini-2.0、Step3 VL 10B、LFM2 1.2B、LFM2.5-VL-1.6B。AAは改訂時に全モデルを再採点するので表記の遅れである可能性が高いと判断して収録しましたが、断定はできません。いずれも低スコア帯なので図の主題には影響しませんが、個別に数値を引用する際は元ページを確認してください。

同一モデルの複数バリアントについて

AAは同じチェックポイントを推論／非推論、あるいは effort（xhigh / high / medium / low）ごとに別行として掲載しています。本ダッシュボードは1チェックポイント＝1点とし、推論版・最上位effortの値を採用しています。両方を載せると点が倍になり、しかもサイズが同一なので縦に重なって読めなくなるためです。参考として、Qwen3.8 27B は xhigh 52 / medium 44 / low 43 / 非推論 35、Qwen3.5 397B A17B は推論 34 / 非推論 33、Qwen3.5 27B は推論 35 / 非推論 30 と、同じ重みでも設定次第で10ポイント以上動きます。この図の点は「そのモデルが出せる上限」に近い値だと理解してください。

また AA のモデルページ・プロバイダページ・比較ページ間で同一モデルの数値が食い違う例が複数あり（Kimi K2 0905 が 31 と 24、DeepSeek V3 0324 が 16 と 22 など）、その場合はバージョン表記が現行に一致する値を採用しました。

Upstage・llm-jp・PLaMo の扱い（重要）

Artificial Analysis は日本の開発元を一社も収録していません。llm-jp（NII）と PLaMo（Preferred Networks / Preferred Elements）はもちろん、Sakana・楽天・SB Intuitions・ストックマーク・富士通・NTT・ソニーも全て未計測です（一方で韓国勢 — Upstage・LG AI Research・SK Telecom・Motif — は収録されています）。AA の日本語ページも Global-MMLU-Lite (Japanese) を約110モデルに走らせているだけで、日本製モデルは1件も入っていません。

そのため llm-jp と PLaMo は縦軸の値が存在しません。パラメタ数（横軸）は公表されているので、正しい横位置のままプロット領域の下の「AA未計測」帯に中空の印で置いています。別ベンチから回帰してAAスコアを推定する、という処理は行っていません（v4.1.1はエージェント系ベンチを34%重み付けしており、日本語MT-Bench等からの外挿は誤差が大きすぎます）。代わりに「日本語 (Nejumi)」ビューを用意しました — Nejumi Leaderboard 4（W&B Japan）は llm-jp を Qwen3.5・Gemma 4・DeepSeek V4 と同一軸で採点している唯一の公開指標です。そこでは llm-jp-4 32B-A3B が 0.6679 で、Gemma 4 31B（0.8077）や Qwen3.5 27B（0.8049）より明確に下、Swallow版 gpt-oss-120B（0.6914）や RakutenAI-3.0（0.6761）と同水準にあります。PLaMo は Nejumi 4 にも見つけられませんでしたため、公開されている比較可能なスコアがありません。

クローズドモデルの扱い

参照用のクローズドモデルはパラメタ数が非公開のため、パラメタ軸ではプロット領域の右外側の帯に縦軸の値だけで並べています（横位置は意味を持ちません）。横軸を「リリース時期」にすると通常の点として表示されます。破線はその時点で観測できるクローズド最高スコアです。なお GLM-5.3（60）は現時点で重み未公開のためクローズド側に入れていますが、AA は重み公開後にオープン首位に並ぶと述べています。オープン／クローズドの区分は時間で変わる点に注意してください。2025年以前のクローズド前線は v4.1.1 基準の公開値が乏しく、点が疎になっています。

色分けについて

点の色はリリース時期（連続量なので単一色相の明度ランプ）で、形は密モデル／MoEを表します。12ファミリーを色で塗り分けていないのは意図的です — 色覚多様性を考慮した散布図で全ペアが識別可能な色数は3程度が上限で、12色に増やすと「見分けられる気がするだけ」の図になります。ファミリーの比較は上部のチップ（クリックで絞り込み、ホバーで強調）と「ファミリー別」ビュー（小分割）で行ってください。

フィルタと軸スケール

横軸・縦軸のスケールはデータセット全体から一度だけ決めて固定しています。リリース時期スライダーやファミリーの絞り込みを操作しても軸の目盛りは動かず、点だけが増減するので、期間を狭めた図と全期間の図を直接重ねて比較できます（縦軸は常に 0–66、横軸は軸の種類ごとに全モデルの最小〜最大）。クローズド帯とAA未計測帯も、該当モデルが0件でも領域を確保したままにしています。
